Modos de edição (clique no mapa):
  • Pan: arrastar o mapa, sem editar a rota.
  • Adicionar: clique insere um ponto na rota.
  • Mover: arraste um ponto para reposicioná-lo.
  • Remover: clique num ponto para apagá-lo.
Ações:
  • +: criar uma nova rota.
  • ✎: renomear a rota selecionada.
  • 🗑: apagar a rota selecionada.
  • Recalcular: refaz o caminho denso (A*) a partir dos pontos.
  • Salvar: grava os pontos editados no banco.
  • Executar: o personagem passa a andar esta rota.
  • Parar: interrompe a execução da rota.
